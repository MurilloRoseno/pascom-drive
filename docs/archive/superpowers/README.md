# Planos Históricos

Este diretório contém planos de implementação antigos criados durante fases anteriores do projeto.

Eles são mantidos por valor histórico, mas não representam necessariamente:

- a arquitetura atual;
- os nomes atuais de arquivos;
- os endpoints atuais;
- os componentes ainda existentes;
- as decisões de escopo vigentes.

Consulte `../../technical-changelog.md` e os documentos canônicos em `../../` antes de reutilizar qualquer decisão.
